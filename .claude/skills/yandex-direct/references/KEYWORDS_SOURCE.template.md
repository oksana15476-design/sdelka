# Ключи-источник для Директа — ШАБЛОН

Скопируй в `references/KEYWORDS_SOURCE.md` и заполни данными своего проекта.
Файл собирает **факт** (что поисковик уже видит) отдельно от **гипотез** (спрос
по Wordstat), чтобы кластеры Директа строились на 100%-интенте.

> Это выгрузка данных конкретного проекта. Если она чувствительна — держи её в
> `.gitignore`, а в репозитории оставляй только шаблон.

## Лист «ВМ — запросы» — реальные запросы из Яндекс.Вебмастера (ФАКТ)

Источник: выгрузка Вебмастера за период `<YYYY-MM-DD – YYYY-MM-DD>`.

Колонки:

```
Запрос | Период | Показы | Клики | CTR, % | Ср. позиция | Кластер | Ценность | Приоритет | Целевой URL | Что сделать
```

Как заполнять:

- **Кластер** — имя тематической группы (один кластер = один JTBD).
- **Ценность** — Высокая / Средняя / Низкая по коммерческому интенту.
- **Приоритет** — например: `A1 — удержать TOP-3` · `A1 — быстрый рост` ·
  `A1 — дожать в TOP-10` · `A2 — усилить` · `A3 — переработать`.
- **Что сделать** — конкретное действие под интент (Title/Description, H2/FAQ,
  перелинковка, новая страница).

## Лист «Семантика» — спрос и гипотезы (Wordstat)

Источник: `yandex-wordstat`, broad-частотность, нужный регион.

```
Фраза | Частотность (broad) | Кластер | Коммерческий интент | Брать в Директ? | Комментарий
```

Правило отбора: высокая частотность ≠ целевой трафик. Информационные «головы» и
омонимичные запросы либо чистятся минус-словами, либо не берутся в поиск вовсе —
им место в контент-воронке и ретаргете.

## Что переносится в кампанию

1. Кластеры с коммерческим интентом → группы ЕПК.
2. Запросы-обманки → стартовый список минус-слов в `PRODUCT_CONTEXT.md`.
3. Целевые URL из листа «ВМ — запросы» → посадочные объявлений (с UTM).
