# `.claude` — набор скиллов и агентов

Универсальный, продукт-независимый набор: **123 скилла** в `skills/` и
**7 агентов** в `agents/`. Ничего не привязано к конкретной компании — контекст
проекта агенты и скиллы читают из репозитория, в котором работают.

## Агенты (`agents/`)

| Агент | Роль |
|---|---|
| `product-agent` | Продуктовая стратегия, приоритизация, нарезка на слайсы, критерии приёмки |
| `development-agent` | Реализация, ревью и верификация фич в существующей архитектуре |
| `design-agent` | UX/UI, дизайн-система, состояния экранов, адаптивность |
| `copywriter` | Черновики пользовательского текста: микрокопи, письма, уведомления |
| `editor-in-chief` | Главред: ревью и приёмка любого пользовательского текста |
| `outreach-architect` | Холодный B2B-аутрич: цепочки касаний, брифы, аудит сообщений |
| `video-director` | Сценарий, раскадровка и тайминг продуктовых роликов (Remotion) |

Связка по тексту: `copywriter` → `editor-in-chief` (ничего не публикуется без
приёмки главреда). Юр-чувствительный текст — на юридическое ревью
(`legal-compliance-ru`), а не через главреда.

## Скиллы (`skills/`)

Крупные группы:

- **Дизайн и UX** — дизайн-система, токены, типографика, цвет, сетки, критики
  экранов, доступность, паттерны форм, состояния загрузки и ошибок, handoff.
- **Контент и бренд** — голос бренда, ревью бренда, UX-копирайтинг, создание
  контента, контент-стратегия и брифы.
- **SEO и маркетинг** — технический и on-page SEO, кластеризация ключей,
  перелинковка, schema.org, аудит битых ссылок, AI-видимость, краулинг.
- **Яндекс-стек** — `yandex-direct`, `yandex-metrika`, `yandex-webmaster`,
  `yandex-wordstat`, `yandex-search-api`.
- **Комплаенс и право** — `legal-compliance-ru` (право РФ), GDPR, ISO 27001,
  ISO 42001, SOC 2, EU AI Act, ISO 13485/14971 и FDA (MedTech), `compliance-os`.
- **Инженерные практики** — TDD, systematic debugging, планирование и исполнение
  планов, code review (запрос и приём), git worktrees, verification before
  completion, `gstack`.

## Как настроить под свой проект

1. Заполни контекст проекта там, где скилл этого просит:
   - `skills/yandex-direct/references/PRODUCT_CONTEXT.template.md` →
     скопировать в `PRODUCT_CONTEXT.md` и заполнить;
   - `skills/yandex-direct/references/KEYWORDS_SOURCE.template.md` → аналогично.
2. Для `legal-compliance-ru` — заполни профиль компании (шаг 0 в скилле) и
   зафиксируй его в `COMPLIANCE.md` проекта.
3. Токены и логины — **только из переменных окружения**. В скиллах лежат
   `config/.env.example`; реальные `.env` закрыты `.gitignore` и не коммитятся.
4. Агенты сами читают `CLAUDE.md`, `README.md`, `HANDOFF.md`, `CHANGELOG.md` и
   `docs/**` целевого репозитория — специфику продукта описывай там.

## Лицензии и атрибуция

Отдельные скиллы — производные работы со своими лицензиями и NOTICE-файлами:
`skills/SUPERPOWERS-LICENSE`, `skills/SUPERPOWERS-NOTICE.md`,
`skills/yandex-direct/NOTICE.md`. Их условия сохраняются.

## Известные оговорки

Пять скиллов подключены симлинками на внешние каталоги плагинов и в этом
репозитории не разрешаются (битые ссылки): `commercial-policy`,
`contract-and-proposal-writer`, `general-counsel-advisor`,
`skills-general-counsel-advisor`, `patent`. Чтобы они заработали, нужен
соответствующий плагин-маркетплейс рядом с репозиторием.
