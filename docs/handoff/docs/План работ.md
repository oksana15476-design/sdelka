## Кабинет покупателя · осталось

### Ломает сценарий

| Что | Почему |
|---|---|
| Кнопка пополнения на самой сделке | Деньги нужны под сделку, а пополнение спрятано в «Мой счёт». Референс должен подставляться из сделки |
| Разбивка счёта по валютам и сделкам | Одна цифра при двух сделках и двух валютах не отвечает, чьи это деньги |
| Пустое состояние первого входа | Кабинет без сделок не спроектирован — первый экран нового клиента |
| Вывод средств | Деньги пришли и должны иметь выход. Только на счёт-источник, 5 состояний |
| Архив закрытых сделок | Закрытые сделки исчезают вместе с документами |

### Заметно, но не блокирует

| Что | Почему |
|---|---|
| Метки «кто держит мяч» в таймлайне | Главное правило флоу на таймлайне не отражено |
| Живой счётчик уведомлений | Не гаснет после прочтения |
| Сообщения по сделке | Стороны общаются вне системы — там их и обманывают |
| Журнал доступа к документам | Клиент имеет право видеть, кто смотрел |
| Настройки уведомлений | Либо спамим, либо клиент пропускает срок |
| Приглашение своего юриста на чтение | Клиент хочет показать сделку своему человеку |
| Реферальная ссылка | Канал роста, по документам основной после застройщиков |

**Итого по кабинету покупателя: 8 страниц из 13.**
