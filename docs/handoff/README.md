Прототипы открываются двойным щелчком в браузере. Внутри есть **панель прототипа** —
переключатели состояний, валют и ширины экрана. Она подписана и на телефоне скрыта:
это инструмент приёмки, в продукт не переносится.

## Главное правило переноса

**Код — источник истины для поведения. Прототип — источник истины для текста,
состояний интерфейса и вёрстки.**

Идентификаторы состояний в прототипе взяты из `packages/domain/src` буква в букву:
`tranche.ts`, `client-account.ts`, `beneficiary.ts`, `freeze.ts`. Если расходятся —
прав код, а прототип надо править.

Тексты в прототипе — черновики, сверенные с `docs/copy/DRAFT-money.md` (ревью главреда
пройдено). Слоты с пометкой ⚖ идут через юриста и **не публикуются** без ревью.

## Что уже решено и не обсуждается

1. **Кабинет один.** Роль — свойство сделки, а не режим кабинета. Ни «кабинета
   покупателя», ни «кабинета продавца» не существует (`CABINETS.md` §0.4).
2. **Участники называются одним словом:** плательщик и получатель. «Покупатель» и
   «продавец» в интерфейсе не встречаются.
3. **Право отзыва и кнопка вывода — разные вещи.** В резерве кнопка закрыта, право
   отзыва существует до подтверждения регистрации. Формулировка в ⚖-слоте.
4. **Ни одного числа внутри текста.** Суммы, даты и сроки приходят слотами и
   форматируются через `Intl`. Сумма стоит отдельной строкой над текстом, а не внутри
   предложения — иначе ломается согласование с числительным.
5. **Консоль — стол исключений, а не конвейер.** 83% сделок проходят без человека;
   человек обязателен в трёх местах: `release_blocked`, второе утверждение по порогу
   суммы, выбор цели разморозки.
6. **Панели прототипа по-русски.** Адресованы команде, не клиенту.

## Порядок работ

Полный список в `docs/Груминг кабинета.md`. Кратко, по приоритету:

**P0 — расхождения с реализацией.**
1. Восемнадцать состояний денег `M-01…M-18` из `apps/web/src/view/money-state.ts`
   вместо двенадцати статусов транша. В прототипе пока двенадцать; пропущены
   `transferDeclared`, `unidentified`, `heldThirdParty`, `onAccountFx`,
   `partiallyFunded`, `overfunded`, `payoutUnknown`, `frozen`.
2. Три текста на состояние по роли: платящая, получающая, оператор.
3. Тексты перенести из `docs/copy/DRAFT-money.md` дословно, по ключам.
4. ⚖-слоты о границе отзыва — одним пакетом, их семь, а не три.

**P1 — чего нет.** Рассрочка (`packages/domain/src/schedule.ts`), пополнение по
`INTAKE.md` целиком, мастер проверки личности (21 состояние).

**P2 — качество.** Бюджеты длины строк на грузинском, полный грузинский перевод,
группировка списка сделок по «требует вашего действия».

## Как проверять сделанное

Приёмка любого экрана:

- на экране есть ответ на «где мои деньги»;
- ответ на «требуется ли что-то от меня» стоит **выше** суммы;
- ни одного второго имени участника;
- ни одной цели касания меньше 44 px;
- ни одной формулировки вины стороны;
- границ отзыва в интерфейсе ровно одна;
- три языка содержательно эквивалентны, грузинский проверяется первым.
