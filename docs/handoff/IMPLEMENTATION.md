## 1. Токены

(`apps/web/src/styles/tokens.css`: `--c-accent: #0b4f8a`) — расхождение зафиксировано,
решение за владельцем. Ниже брендовые значения.

```css
--c-line:      #ECEFF3;   /* граница карточки */
--c-line-2:    #DCE3EE;   /* граница поля */

--c-ink:       #0F1729;   /* основной текст */
--c-ink-2:     #34405A;   /* тело */
--c-ink-3:     #56637A;   /* второстепенное */

--c-accent:    #2D5BFF;   /* действие */
--c-accent-h:  #1E3FBF;   /* наведение */
--c-accent-a:  #172E8C;   /* нажатие */

```

**Правило семантики:** цвет никогда не единственный носитель состояния. Каждое
состояние несёт цвет + форму знака (● ○ ✓ ▲ ■ ◇) + текст.

**Шрифты.** Manrope для интерфейса, IBM Plex Mono для сумм, кодов и дат,
Noto Sans Georgian добором для мхедрули. Знак лари ₾ — в слоте фиксированной ширины
`.62em`: глифа нет ни в Manrope, ни в IBM Plex Mono, без слота колонка сумм плывёт.

**Радиусы:** 8 поле, 10–12 кнопка и плашка, 14–18 карточка, 22 рамка устройства.
**Тень карточки:** `0 1px 2px rgba(15,23,41,.04), 0 1px 3px rgba(15,23,41,.06)`.

## 2. Машины состояний в интерфейсе

Идентификаторы — из кода, буква в букву.

### 2.1 Транш · `packages/domain/src/tranche.ts`

`pending` · `collecting` · `collected` · `reserved` · `release_pending` ·
`release_blocked` · `paying_out` · `paid_out` · `refund_pending` · `refunding` ·
`refunded` · `written_off`

Поведение экрана по состоянию:

| Признак | Где действует |
|---|---|
| Подтверждение резервирования показывается | `reserved`, `release_pending`, `release_blocked`, `paying_out`, `paid_out` |
| Блок «Срок» показывается | `collecting`, `collected`, `reserved`, `release_pending`, `release_blocked` |
| ⚖-слот о праве отзыва показывается | `collecting`, `collected`, `reserved` |
| Кнопка пополнения показывается | `collecting`, `collected` |
| Карточка денег скрыта | `pending` |
| Расшифровка расчёта скрыта | до `collected` |
| Возвратная модель итога | `refund_pending`, `refunding`, `refunded` |
| Историческая модель итога | `written_off` |

**Три модели итоговой суммы, не одна:**
расчёт → «К получению»; возврат → «К возврату» / «Возвращено вам» за вычетом
невозвратной комиссии за конвертацию, комиссия за организацию расчёта **не**
удерживается; `written_off` → «Внесено по сделке» как историческая справка без
требования.

### 2.2 Вывод · `client-account.ts`

`requested` · `approved` · `paying_out` · `paid_out` · `blocked` · `cancelled`

Отмена доступна только в `requested` — перехода `approved → cancelled` в машине нет,
поэтому кнопки быть не должно. В `paying_out` повторная заявка запрещена
(`g_no_active_withdrawal`), и причина названа словами заранее, а не отказом в момент
нажатия.

### 2.3 Реквизиты получателя · `beneficiary.ts`

`draft` · `awaiting_verification` · `verified` · `cooling` · `locked` · `rejected`

Форма редактируема везде, кроме `locked` (держит резерв) и `awaiting_verification`
(идёт сверка). Охлаждение 48 часов подаётся как защита от подмены реквизитов,
а не как задержка выплаты.

### 2.4 Заморозка · `freeze.ts`

Цели разморозки `suspended_from` · `refund_pending` · `release_blocked` —
**операторский экран**, в клиентском кабинете их не показывать. Клиенту: операции
приостановлены, деньги на номинальном счёте, решение принимают двое сотрудников,
срок разбора, номер обращения, итог сообщается обеим сторонам одновременно.

### 2.5 Котировка и зачисление · `packages/intake/src`

Котировка: `fresh` · `expiring` · `expired` · `requoting` · `unavailable` · `same`.
При `expired`, `requoting`, `unavailable` **сумма в лари скрывается** — показывать
цифру по курсу, которого уже нет, нельзя. `unavailable` помечен как решение
владельца: принимать деньги без курса или блокировать пополнение.

Зачисление: `none` · `seen` · `credited` · `short` · `excess` · `thirdParty` · `noRef`.
Излишек уходит в свободную часть счёта **немедленно**, не после закрытия сделки
(`FUNCTIONAL.md` §4.3.2).

## 3. Мультивалютность

Две независимые величины:

- **Валюта сделки** — три: GEL, USD, EUR. Каждая означает отдельный счёт номинального
  держания, отдельную сверку и отдельный контроль покрытия.
- **Валюта перевода** — топ-10 мировых: клиент платит из своего банка.

Когда они совпадают, конвертационный слой **исчезает целиком**: нет строки курса, нет
комиссии за конвертацию, вместо них прямая фраза, что конвертации не было. Курс 1:1 не
показывается никогда.

Остатки в разных валютах **не суммируются**. Единой суммы «всего у вас» не существует,
и в интерфейсе она не появляется.

## 4. Тексты

### Ключи

Схема из `docs/copy/DRAFT-money.md` §3:

```
deal.paying.where.<state>.{title,body,amountLabel,revocation}
assurance.state.<state>.{title,subtitle}
assurance.{limits,revocationClosed,whereMoney.title,whereMoney.body,reservedAt}
ops.money.<state>.{label,note}
deals.state.<state>.{paying,receiving,ops}
deal.<role>.timeline.<state>.{detail,insert,insert.detail}
```

Ключи не переиспользуются между областями даже при совпадении русского текста:
в грузинском он может не совпасть.

### Бюджеты длины

Меряются на грузинском, он длиннее русского примерно в полтора раза.

| Слот | Лимит |
|---|---|
| Заголовок блока «где деньги» | ≤ 44 знака |
| Тело блока | ≤ 240 знаков, ≤ 3 предложения |
| Метка суммы | ≤ 24 знака |
| Чип состояния в списке сделок | ≤ 32 знака |
| Название шага ленты | ≤ 34 знака |
| ⚖-слот | ≤ 200 знаков |

### Глоссарий — одно слово на вещь

резерв · расчёт · поручение · поступление · счёт-источник · банковский день ·
объект сверен с реестром · счёт номинального держания · плательщик · получатель ·
сделка не состоялась.

Запрещено: эскроу, спред, заморозка, гарантируем, безотзывно, 100%, полная защита,
мгновенно, проверено юридически, откат в клиентском интерфейсе, «перевести продавцу».

## 5. Адаптив

Брейкпоинты **контейнерные**, а не оконные: ширину задаёт оболочка. Это нужно, чтобы
мобильная раскладка проверялась на широком экране и была та же самая, что на телефоне.

| Ширина | Поведение |
|---|---|
| ≥ 1024 | боковая навигация 248 px, содержимое до 880 px |
| ≤ 1023 | тонкая шапка с бургером; сайдбар — выдвижная панель 274 px со своей прокруткой; затемнение по фону |
| ≤ 767 | панели прототипа скрыты, карточки плотнее, заголовок 21 px |
| ≤ 479 | строки «подпись — значение» в столбик, поля 16 px против зума iOS, кнопки во всю ширину, сумма 27 px |

Цели касания: ни одной меньше 44 px, в панели 46. Закрытая панель убрана из фокуса,
а не только из вида.
